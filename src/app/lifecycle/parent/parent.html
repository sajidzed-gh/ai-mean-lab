Parent Component

Event happens → Change Detection (the engine) runs → Hooks execute-(checkpoints inside the engine) → UI updates

  1. constructor(once) → basic setup & dependency injection (no Angular-specific logic)
  2. ngOnChanges(in input ref changes) → react to @Input() reference changes
  3. ngOnInit(once) → run one-time initialization after inputs are set
  4. ngDoCheck(every change detection cycle) → perform custom/manual change detection
  5. ngAfterContentInit(once) → act when projected content <ng-content/> is first available
  6. ngAfterContentChecked(on every change detection cycle) → respond after each projected content check
  7. ngAfterViewInit(once) → access/view child components or DOM after init
  8. ngAfterViewChecked(on every change detection cycle) → respond after each view check (avoid heavy work)
  9. ngOnDestroy(once) → clean up subscriptions, timers, and resources
